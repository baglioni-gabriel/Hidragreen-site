# 🌿 Hidragreen - Website e Portfólio Corporativo

Este repositório contém o código-fonte do website oficial da **Hidragreen**, uma empresa especializada em engenharia de irrigação e paisagismo. O projeto funciona como uma vitrine digital para o portfólio da empresa e incorpora um sistema automatizado para a captação e gestão de contatos de potenciais clientes.

## 🚀 Funcionalidades Principais

* **Vitrine de Serviços:** Apresentação responsiva dos projetos de paisagismo e soluções de engenharia de irrigação.
* **Automação de Captação (Leads):** Sistema de formulário integrado que utiliza fluxos de automação no **n8n** para capturar, processar e rotear automaticamente as mensagens para os canais de atendimento da empresa.
* **Interface Dinâmica:** Componentes front-end desenvolvidos para garantir um carregamento rápido, excelente navegação e otimização para motores de busca (SEO).

## 🛠️ Tecnologias Utilizadas

* **Front-end:** React / Next.js *(Ajuste caso tenha usado HTML/JS puro ou outro framework na construção dos componentes)*
* **Automação e Integração:** n8n (Workflows de captação de contatos e disparo de notificações)
* **Estilização:** CSS / Tailwind CSS *(Adapte conforme a sua stack)*
